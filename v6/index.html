Export Scout

v6.0 DEV · 非公開開発版

日本商品をジャンル横断で探す。海外の需要と国内の仕入れ候補を、根拠とともに。

AUTO DISCOVERY

調べる時間を減らして、
見つける時間を増やす。

日本関連商品ならジャンルを限定せず、海外の成約参考データと国内仕入れ価格を照合する。実際にAPIで取得できた商品だけを掲載する。

安全な開発モード

v6.0は開発中。既存の保存商品や売却履歴にはアクセスせず、Firebaseにも接続しません。現在のv5.6はそのまま使えます。

商品を探す

すべてのジャンルが対象

値段だけで利益を断定しません。海外の成約参考値がない商品・仕入れ価格が古い商品は「要確認」として別表示します。

GitHub Actionsで取得した確認用JSONを、このブラウザ内だけで開きます。データはアップロード・保存されません。公開ホームのデータは変更しません。
